# Oremi Akọrin coding skills

This package contains four repository-specific skills designed for AI-assisted development of Oremi Akọrin.

- `oremi-akorin-coding-agent`: default workflow for implementation and debugging.
- `oremi-akorin-performance`: real-time latency and throughput constraints.
- `oremi-akorin-testing`: repository-specific testing workflow.
- `oremi-akorin-architecture-review`: architecture and boundary review for significant changes.

These skills are designed to complement the repository's `AGENTS.md`, not replace it.
